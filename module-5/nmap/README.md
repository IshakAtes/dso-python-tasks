  Nmap in Python ✍️
Programmiere die Grundfunktionalität von nmap als Kommandozeilenprogramm in Python nach. Das Programm soll Folgendes können:

Dein Programm soll sowohl numerische IP-Adressen (z. B. 10.0.2.17) als auch DNS-Adressen (z. B. developerakademie.com) verwendet werden können.
Mit dem nicht optionalen Parameter -p soll unter Angabe des Port-Bereichs durch min und max definiert werden, welche Ports gescannt werden. Mit -p- werden alle Ports gescannt.
Es soll nur angegeben werden, ob der Port offen oder geschlossen ist. Für die ersten 100 Ports soll zusätzlich noch die dahinter laufende Anwendung benannt werden.
